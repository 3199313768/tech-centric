# Kenney Mini Forest

These GLB files are from Kenney's [Mini Forest](https://kenney.nl/assets/mini-forest) asset pack.
The pack is released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); the original license is included in `License.txt`.

The homepage uses the building platform, structure, and roof meshes as the authored cabin model.
